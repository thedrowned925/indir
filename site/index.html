Nasıl çalışıyor?
  1. İndir'e bastığında site, bu depoda başlığı [indir] olan bir issue açar (ayarlara token girdiysen otomatik; yoksa GitHub sekmesinde yeşil Create düğmesine basman yeter).
  2. GitHub Actions bu issue'yu görür, sunucuda yt-dlp + ffmpeg ile istediğin formatta indirir/dönüştürür.
  3. Dosya depo içinde bir Release'e yüklenir, issue'ya bağlantı yazılır ve bu sayfada indirme düğmesi belirir.
  4. Eski dosyalar her gün otomatik silinir. 2 GB'tan büyük dosyalar parçalara bölünür.

Ayarlar

Token girersen issue'lar otomatik açılır ve API sınırı 60'tan 5000/saate çıkar. Fine-grained token oluştur: sadece bu depo, Issues: Read and write izni yeterli. Token yalnızca bu tarayıcıda saklanır.
